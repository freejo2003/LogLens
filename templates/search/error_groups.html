How Grouping Works

LogLens groups recurring log messages using normalized message templates.

Timestamp normalization
Variable timestamp prefixes are removed before messages are compared.
Variable-value normalization
Variable values such as key-value fields and duration values are normalized so recurring message structures can be grouped.
Case normalization
Case differences are normalized so equivalent message templates can be grouped together.
